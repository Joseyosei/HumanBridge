# Product requirements

Target: adults aged 18–40; English-language UK pilot proposed. Not diagnosis, therapy or crisis monitoring.

| ID | Requirement | Acceptance criterion | Status |
|---|---|---|---|
| FR01 | Age eligibility | User acknowledges range before entry | Demo |
| FR02 | Check-in | Optional 1–5 input with explicit save | Demo |
| FR03 | Action plan | User can mark each suggested action complete | Demo |
| FR04 | Coaching | Clearly labelled rule-based suggestions | Demo |
| FR05 | Explore | Examples distinguished from real events | Demo |
| FR06 | Progress | Count completed tasks and latest saved check-in | Demo |
| FR07 | Support | UK support links and crisis disclaimer available | Demo |
| FR08 | Accounts | Authenticated sessions, deletion, tested isolation | Planned |
| FR09 | Validated assessment | Approved wording, scoring, no clinical inference | Planned |
| FR10 | AI plan | Constrained output, safety evaluation, user control | Planned |
| FR11 | Event discovery | Verified source and timestamps, optional broad location | Planned |

Nonfunctional targets for future pilot: WCAG 2.2 AA where applicable, screen-reader checks, scalable text, TLS, least privilege, audited access, deletion workflow, rate limits, no sensitive logs, and a documented incident response plan. No engagement-maximisation objectives.
