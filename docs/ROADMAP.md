# Roadmap

1. Foundation: prototype, research plan and architecture (this release).
2. Verify mobile build on both platforms; lock dependencies; accessibility tests.
3. Authentication, migrations, access policies and secure API integration.
4. Curated interventions, AI recommendation and safety evaluation.
5. Verified event discovery, opt-in reminders and deletion controls.
6. Ethics-approved pilot, outcome analysis and iteration.
7. Store preparation, security review and release.

Friend matching, messaging and voice coaching are deferred until safeguarding capacity exists.
